# プロダクト概要

Mintgreen（いどばた政策政策 みんなの共感表明）は、デジタル選挙と政策フィードバックのために構築されたモダンなオンライン投票システムです。このアプリケーションは、有権者登録から結果表示まで、選挙プロセス全体をサポートし、安全で効率的な投票プロセスを実施するためのプラットフォームとして機能します。

## 主要機能

- **有権者登録**: 身分証明書番号による有権者の登録・管理
- **GitHub Issues評価**: GitHub Pull Requestsの自動同期と投票機能
- **Issue ランキング**: コミュニティ投票とGitHubリアクションに基づくリアルタイムランキングシステム
- **認証**: Supabaseによる安全なユーザー認証

## 対象ユースケース

- デジタル政策投票とフィードバック収集
- コミュニティ主導のGitHub Pull Requests評価
- 公開投票追跡による透明な意思決定プロセス
- コードリポジトリと民主的プロセスの統合

## 主な特徴

- 日本語インターフェースとドキュメント
- リアルタイムデータ同期
- 公開結果による透明な投票
- 技術政策議論のためのGitHub統合
